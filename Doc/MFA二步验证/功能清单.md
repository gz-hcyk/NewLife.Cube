## 验收打勾

- [ ] EnableMfa=false → 密码直接登录
- [ ] EnableMfa=true + 用户已绑 MFA → 必须挑战成功
- [ ] TOTP / SMS / Mail / Backup 均可过关
- [ ] MfaRequired + 未绑定 → 不发 Token，引导绑定
- [ ] 恢复码一次性失效
